================================================================================
  ENTERPRISE APACHE FLINK EVENT CORRELATION PIPELINE - EXECUTION MANUAL
================================================================================

PIPELINE ARCHITECTURE:
- Two independent Kafka streams (topic_a: RAN reports, topic_b: MME events).
- Normalization & validation with deterministic ID generation (SHA-256).
- Payloads offloaded to Aerospike; lightweight ShadowEvents stored in RocksDB state.
- Order-agnostic stateful correlation via keyBy(common_id) where common_id is IMSI.
- Payload multi-get retrieval from Aerospike upon match and deep merge.
- Final output published to Kafka topic 'merged_events'.
- Multi-tier DLQ routing for validation, timeouts, Aerospike errors, and anomalies.

STEP 1: START INFRASTRUCTURE (DOCKER COMPOSE)
================================================================================

Open PowerShell in the project directory (c:\Users\2857155\Desktop\EOL_Final):

    docker compose up -d
    docker compose start

Verify all containers are up and healthy:

    docker compose ps

Running Components:
  - Kafka Broker (KRaft mode, Port 9092)
  - Aerospike Cluster (Port 3000)
  - Flink JobManager (Web UI: http://localhost:8081)
  - Flink TaskManagers (2 replicas, 8 total task slots)

================================================================================
STEP 2: BUILD & PACKAGE (FAST WITH LOCAL CACHE)
================================================================================

Compile and package the shaded application JAR using the persistent cache:

    docker run --rm -v "${PWD}:/app" -v maven-repo:/root/.m2 -w /app maven:3.9.6-eclipse-temurin-17 mvn package -DskipTests

Output Fat JAR:
    target/flink-event-correlation-1.0.0.jar

================================================================================
STEP 3: PROVISION KAFKA TOPICS
================================================================================

Create the 10 ingestion, egress, and DLQ topics:

On Windows PowerShell:
    .\scripts\create-topics.ps1

On Linux / macOS / Bash:
    ./scripts/create-topics.sh localhost:9092 12 1

Topics:
  - topic_a           (Source A: RAN Measurement Reports)
  - topic_b           (Source B: MME Core Network Events)
  - merged_events     (Sink: Final Correlated and Merged Events)
  - shadow_events     (Sink: Lightweight Shadow Event Metadata)
  - payload_events    (Sink: Full Raw Payload Event JSON)
  - validation_dlq    (Malformed records / missing IMSI)
  - aerospike_dlq     (Storage write failures after retries)
  - correlation_dlq   (Unmatched events after timeout)
  - payload_fetch_dlq (Missing Aerospike payload errors)
  - processing_dlq    (Merge / execution anomalies)

================================================================================
STEP 4: SUBMIT STREAMING JOB TO FLINK CLUSTER
================================================================================

Submit the application to Flink JobManager:

    docker exec flink-jobmanager ./bin/flink run -d -c com.company.flink.Application /opt/flink/project/target/flink-event-correlation-1.0.0.jar --kafka.bootstrap.servers kafka:29092 --aerospike.hosts aerospike:3000

(Note: In WSL Ubuntu without Docker Desktop WSL-integration enabled, run `docker.exe` instead of `docker`)

Check running jobs:

    docker exec flink-jobmanager ./bin/flink list
    # or in WSL: docker.exe exec flink-jobmanager ./bin/flink list

Open the Flink Dashboard in your browser:
    http://localhost:8081
